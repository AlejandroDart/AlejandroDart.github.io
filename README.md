# Presentación profesional V5 — Alejandro Mayró Lena

Portafolio estático con estética de cristal, fondo de ingeniería animado, lluvia digital ambiental, lente holográfica, tarjeta 3D, terminal personal, constelación tecnológica, navegación fija, formación y certificaciones. La V5 incorpora laboratorio interactivo para tres proyectos, paleta de comandos `Ctrl + K`, telemetría AM/SYS, credenciales expandibles, mapa tecnológico de Chile e insignias persistentes. Diseñado para GitHub Pages.

Incluye el easter egg romántico público del pie de página.
